# Cubixora SMP Discord Bot

Türkçe Discord moderasyon ve Minecraft topluluk botu.

## Render

- Build Command: npm install
- Start Command: node dcs.js
- Health path: /health

Gerekli environment değerleri: DISCORD_TOKEN, CLIENT_ID, GUILD_ID, MC_HOST, MC_JAVA_PORT ve MC_BEDROCK_PORT. Tokeni GitHub'a koyma; Render Environment Variables bölümünde sakla.

## Replit

Replit'te botu pnpm run bot ile çalıştırabilirsin. Telefon veya bilgisayar kapansa bile sürekli çalışma için Render'da sürekli çalışan bir servis kullan.

## Discord

Bot Developer Portal'da Message Content Intent, Server Members Intent ve Presence Intent açık olmalıdır.
